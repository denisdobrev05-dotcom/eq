# 🎵 Аудио Ефекти — Slowed & Sped up + Reverb (PWA)

Лично приложение за аудио ефекти на български език. Работи изцяло в браузъра,
без сървър и без качване на файлове никъде — обработката се случва на твоето
устройство чрез **Web Audio API**. Може да се инсталира на началния екран на
iPhone като PWA (цял екран, икона, offline режим).

## Възможности

- **Два режима:** „Slowed + Reverb“ и „Sped up + Reverb“.
- **Пресети с едно докосване** (по 5 за всеки режим) — задават скорост + reverb + бас наведнъж.
- **Ръчни настройки:** скорост (0.5x–1.5x), reverb (сухо/мокро), bass boost
  (0…+12 dB), сила (loudness), компресор и 3-лентов еквалайзер (ниски/средни/високи).
- **Reverb** чрез `ConvolverNode` със синтетичен импулсен отговор, генериран в кода (без външен файл).
- **Play/Pause** в реално време, докато местиш плъзгачите, с кръгъл индикатор за прогрес.
- **Запази като WAV** — експорт чрез `OfflineAudioContext`.

### Верига на сигнала
```
източник → скорост → еквалайзер → bass boost → компресор → loudness → reverb → изход
```

> Обработката подобрява звученето, но не може да върне качество, което липсва в оригинала.

## Стартиране от GitHub Pages

1. В настройките на репото → **Settings → Pages**.
2. **Source:** Deploy from a branch, **Branch:** избраният branch, папка `/ (root)`.
3. Отвори публикувания URL на iPhone в Safari → **Споделяне → Добави към „Начален екран“**.

Чист HTML/CSS/JS — без build процес и без външни библиотеки.

| `sw.js` | Service worker за offline |

| `icons/` | Икони (180/192/512) |
